
# SKILL BHARAT 3D ARCHITECT PRO

A free 2D and 3D architecture design project.

## Features
- 2D room planning
- Room editing
- Local project storage
- Import and export project JSON
- Responsive interface

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
